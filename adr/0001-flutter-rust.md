# ADR-0001：Flutter UI + Rust Core

- 状态：Accepted
- 日期：2026-07-27

## 背景

项目由独立开发者推进，需要同时覆盖桌面与移动平台，又需要可靠的密码学、同步、存储和网络核心。

## 决策

使用 Flutter 实现 UI，Rust 实现共享核心。通过粗粒度异步 API 和状态流连接两者。

## 后果

优点：

- 单套 UI 代码覆盖多个平台。
- 核心协议和存储逻辑只有一份。
- 服务节点可以复用 Rust 模块。

代价：

- 需要维护 FFI 生成和兼容性。
- 某些平台特性仍需原生插件。
- 必须避免过细的跨边界调用。
