# ADR-0002：角色型节点网络

- 状态：Accepted
- 日期：2026-07-27

## 背景

手机、桌面、NAS 和 VPS 的在线时间、带宽、存储及公网可达性差异巨大。

## 决策

不要求节点完全同质，而是定义 Light、Full、Service、Seed 四类能力等级，并使用可组合角色声明 Bootstrap、Relay、Mailbox、Blob 等服务。

## 后果

优点：

- 能适应移动系统后台限制。
- 普通用户和社区可以逐步承担服务。
- 公共节点可替换且可以专业化部署。

代价：

- 需要服务发现、能力声明和节点选择。
- 需要考虑恶意声明、配额和健康检查。
